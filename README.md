# Netflix 影视数据预处理与多维分析

## 项目简介
基于 Hadoop 与 Spark 分布式计算框架，对 Netflix Movies and TV Shows 数据集进行数据预处理、多维度统计分析与可视化展示，覆盖数据处理全链路。

## 技术栈
- 分布式计算：Spark 3.2.0 (PySpark)
- 分布式存储：Hadoop HDFS 3.1.3
- 数据处理：Python Pandas, NumPy
- 可视化：Matplotlib, Seaborn, Plotly
- 环境：Linux (Ubuntu 16.04), Jupyter Notebook, Python 3.8

## 项目流程
1. **环境搭建**：在 Ubuntu 虚拟机上配置 Hadoop + Spark 集群，编译安装 Python 3.8.12 解决系统 Python 版本兼容问题。
2. **数据预处理**：使用 Pandas 对 Netflix 数据集进行缺失值填充、日期解析、字段提取，生成清洗后的结构化数据。
3. **分布式存储**：将清洗数据上传至 HDFS，供 Spark 读取。
4. **多维分析**：使用 PySpark 完成以下统计：
   - 电影与电视剧占比分析
   - 按年份统计新增节目数量
   - 各国影视剧总量 Top10 排名
   - 各国家内部电影/电视剧占比
5. **可视化呈现**：在无图形界面环境下使用 Agg 后端生成饼图、柱状图。

## 难点与解决
- **数据字段错位**：年份统计结果中出现导演姓名，根因为 CSV 分隔符与列名引号格式导致字段错位。改用制表符分隔并统一去除列名引号，从源头解决元数据传递中的格式丢失问题。
- **环境兼容性**：系统默认 Python 3.5 不支持 Spark 3.2.0，通过源码编译安装 Python 3.8.12 解决。
- **无图形界面可视化**：Ubuntu 服务器无桌面环境，使用 Matplotlib 的 Agg 后端直接将图表保存为 PNG 文件。

## 项目收获
- 完整实践了数据获取、清洗、分布式存储、分布式计算、可视化、报告展示六大环节。
- 深刻认识到数据质量保障必须作为流程的内置环节，而非事后补救。
- 具备独立解决跨组件兼容性问题的能力。
